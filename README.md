the # TECH ZONE - LIVE-READY WEBSITE
This package contains a responsive Tech Zone storefront.
Run locally:
1. Install Node.js 18+
2. In this folder run: pm install
3. Run: npm start
4. Open http://localhost:3000
IMPORTANT:
This is the storefront, not a public internet deployment and not a live payment account.
Before accepting real orders, connect a payment provider, verify product costs/stock, shipping, taxes, and business/legalmy-website
